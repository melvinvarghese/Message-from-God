# Message from God — Inspirational Messages for Hope, Peace & Reflection

Take a quiet moment with a random inspirational message about hope, peace, courage, kindness, healing, and personal growth. **Message from God** is a free, lightweight reflection website featuring messages. The messages run in your browser, with no account, backend, or build step required.

[Visit the live site](https://melvinvarghese.github.io/Message-from-God/)

## Features

- Inspirational reflections across 46 themes, including hope, peace, courage, kindness, and personal growth
- A randomly selected message on each page load, with no immediate repeat in the same browser tab session
- Share a message with your device’s native share sheet or copy it to the clipboard
- Responsive layout for phones, tablets, and desktops
- Keyboard-accessible controls, visible focus styles, a skip link, live announcements, and reduced-motion support
- Built with plain HTML, CSS, and JavaScript; no framework, API key, backend, or build process

## Run locally

Open `index.html` in a browser, or start a local static server from the repository directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## About the messages

These are welcoming inspirational reflections, not claims of literal divine revelation or a substitute for personal, spiritual, or professional guidance.
